# Northstar

Experimental Telltide variant: tracks outcomes of its own large river calls at showdown. After 12 such showdowns, a smoothed win rate below 30% gates some folds; one fifth of qualifying calls remain to detect opponent changes. This is a heuristic with selected showdown data, not an equilibrium guarantee.

In matched 1,000-deal tests on seeds 8500–8502, average bb/deal changes versus Telltide were +0.052 against Anchor, −0.009 against Kestrel, +0.031 against Turnblade, −0.002 against Stones, +0.025 against Ederson, and −0.004 against River Ruse. These small differences are not proof of an edge.

The full-roster three-seed run was still in progress at initial publication.
